# Triage Labels

Map the canonical roles to the exact labels used by this repository:

- `needs-triage`: not configured upstream; use as local markdown status when needed.
- `needs-info`: not configured upstream; use when school endpoint captures, screenshots, or credentials-dependent traces are missing.
- `ready-for-agent`: not configured upstream; use after a task has fixtures and a clear acceptance test.
- `ready-for-human`: not configured upstream; use when a live school account or iOS device verification is required.
- `wontfix`: not configured upstream; reserve for Android-only behavior that is intentionally replaced on iOS.
