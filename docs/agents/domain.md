# Domain Docs

This project uses a layered project-context layout:

- `CONTEXT.md` at the repository root
- `PROJECT_MEMORY.md` at the repository root
- `docs/adr/` for architectural decisions

Read `CONTEXT.md` before planning or implementing substantial changes.
Read `PROJECT_MEMORY.md` before changing existing workflows, modules, or user-facing capabilities.
Read relevant ADRs before changing established decisions.
