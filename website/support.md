# 支持

岱宗盒子是非官方独立开发项目，与西安交通大学官方无关。使用前请确认你信任当前安装来源，并只在自己的设备上输入统一身份认证账号。

## 反馈渠道

- GitHub Issues：[yeliqin666/xjtu-toolbox-android](https://github.com/yeliqin666/xjtu-toolbox-android/issues)
- Gitee Issues：[yeliqin666/xjtu-toolbox-android](https://gitee.com/yeliqin666/xjtu-toolbox-android/issues)

## 反馈前请准备

请尽量提供以下非敏感信息，方便定位问题：

- 应用版本和构建号。
- 系统版本、设备型号，以及当前使用的是校园网、校外网络还是 WebVPN。
- 出问题的功能入口，例如登录、课表、成绩、校园卡、空教室、图书馆座位、加餐券或全校课程搜索。
- 具体操作步骤、错误提示文字、发生时间和是否可以稳定复现。

请不要提交账号密码、验证码、Cookie、票据、令牌、完整网页响应、HAR 文件或未遮挡的个人截图。截图中请遮挡学号、姓名、手机号、课程成绩、校园卡交易等个人信息。

## 常见问题

### 清除缓存会删除登录凭据吗？

不会。清除缓存只清除功能数据缓存；已保存的登录凭据由 iOS Keychain 管理。需要清除凭据时，请在应用内退出登录，或卸载应用并清除本机应用数据。

### 为什么某些功能需要重新授权？

学校不同系统的登录态可能分别过期。应用会尽量只在对应功能里提示补授权，而不是要求全局退出重登。

### 官方浏览器登录为什么不可用？

当前学校 CAS 尚未接受应用回调地址并返回应用可读取的登录结果，因此 iOS 首发版本默认使用应用内统一认证流程。官方浏览器登录会在学校侧支持后再开放。

### 可以把错误截图直接发到公开 issue 吗？

可以，但必须先遮挡个人信息。不要公开账号、密码、验证码、Cookie、票据、令牌、成绩明细、校园卡交易、手机号或其他可识别个人身份的信息。
